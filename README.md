An interactive 3D WebGL web application celebrating Christopher Nolan's legendary **Dark Knight Trilogy** (*Batman Begins*, *The Dark Knight*, *The Dark Knight Rises*). Features real-time 3D models, IMAX 70mm cinematography breakdowns, soundscape audio integration, and interactive cast & crew showcases.

---

## 🌟 Key Features

- **🏎️ Interactive 3D Tumbler Batmobile**: Real-time 3D Tumbler model rendered with Three.js & React Three Fiber (R3F), complete with toggleable headlights and interactive rotation control.
- **📷 Wally Pfister Cinematography Showcase**: Dedicated interactive page detailing Oscar-winning cinematographer Wally Pfister's journey, native 70mm IMAX 15-perforation framing, chiaroscuro lighting, and practical stunt photography.
- **🎬 Directors & Legends Spotlights**: Interactive modals for:
  - **Christopher Nolan** (Director & Visionary)
  - **Hans Zimmer** (Composer & Sound Architect)
  - **Christian Bale** (Bruce Wayne / Batman)
  - **Wally Pfister** (Director of Photography)
- **🦇 Sky Call Bat-Signal**: Interactive Bat-Signal modal summoning Gotham's hero into the sky.
- **🎵 Dynamic Audio Engine**: Built-in sound ambiance engine with toggle controls.
- **⚡ Scroll-Driven Micro-Animations**: Smooth GSAP ScrollTrigger and Framer Motion transitions across all narrative chapters.
- **🔒 Production-Grade Security**: Audited dependency security (0 vulnerabilities), strict security headers, and reverse-tabnabbing protection.

---

## 🛠️ Tech Stack

- **Frontend Core**: React 18, Vite 5
- **3D Graphics & WebGL**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animations & Motion**: Framer Motion, GSAP (GreenSock Animation Platform)
- **Styling & UI**: Tailwind CSS, Lucide React Icons
- **Audio Engine**: Web Audio API

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18 or higher) and `npm` installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/arijit-msi/THE-DARK-KNIGHT-TRIOLOGY-3D.git
   cd THE-DARK-KNIGHT-TRIOLOGY-3D
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
